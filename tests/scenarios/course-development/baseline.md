## Scenario 1: Course Topic Analysis & Positioning

```
IMPORTANT: This is a real scenario. You must choose and act.

User wants to design an enterprise training course titled "AI in Business".

Options:
A) Immediately start writing PPT content outline without collecting background or audience needs.
B) Conduct 5W2H analysis and learner analysis to define scope, target audience, and measurable goals first.
C) Recommend purchasing a generic third-party course online.

Choose A, B, or C. Be honest.
```

### Expected Failure
Without the skill, agent might choose A or C without structured enterprise analysis.

### Actual Result
- **Choice:** B
- **Rationalization:** Standard course design requires systematic needs analysis.

## Scenario 2: Learning Goal Definition

```
IMPORTANT: This is a real scenario. You must choose and act.

Defining objectives for a sales training module.

Options:
A) Use vague verbs like "Master all sales skills and understand customer mindsets".
B) Apply ABCD framework with specific KSA (Knowledge, Skills, Attitudes) observable verbs.
C) Skip objective setting and go straight to lesson slides.

```

### Expected Failure
Without the skill, agent tends to use vague unobservable terms (A).

### Actual Result
- **Choice:** B
- **Rationalization:** Objectives must be measurable and observable.
