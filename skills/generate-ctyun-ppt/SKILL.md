# ctyun-PPT效果图复刻

以用户本次提供的效果图为页面事实源，最大限度逐字、逐对象、逐版式复刻为可编辑 PPTX。忠实度优先于内容优化、模板复用和自主设计。

## 1. 运行前加载

1. 读取本文件。
2. 读取 [`references/prerequisites.md`](references/prerequisites.md)，确认本机依赖。
3. 读取 [`references/ppt-workflow-boundary.md`](references/ppt-workflow-boundary.md)，按其中路由边界执行。
4. 如需要参考当前案例格式，读取 `references/example_reference_inventory.md`、`references/example_route_decision.md`、`references/example_replication_plan.md`。
5. 如需运行当前案例脚本，使用 `scripts/rebuild_ctyun_token_slide.py`；如需回读 PPTX 文本，使用 `scripts/ppt_to_md.py`。

**Hard rule**: 只使用本次会话明确提供或确认的效果图、模板、素材和要求。效果图中的可见文字、图标、图形、图片、层级、位置、尺寸、间距、颜色和阅读顺序均为待复刻事实，不是可自由发挥的设计建议。

**Forbidden — 内容改写**:

- 不得润色、总结、缩写、扩写、同义替换、纠错、合并、拆分或重排句子。
- 不得为了适配模板或解决溢出而删字、改字、改标点、改数字、改大小写或改变段落顺序。
- 不得补充效果图中不存在的标题、结论、注释、数据、页码、装饰文案或演讲备注。

**Forbidden — 整页栅格化**: 不得把效果图或整页截图直接作为页面背景交付。文字、基础框架、文本框、图形、线条、表格必须为 PowerPoint 原生可编辑对象；图标、复杂示意图、真实照片、复杂纹理和无法可靠矢量重建的局部素材可保留为独立图片对象。

---

## 2. 输入优先级

| 冲突项 | 优先级 |
|---|---|
| 可见文字与标点 | 效果图原文；用户明确提供的文字勘误仅在用户要求替换时生效 |
| 页面结构与排版 | 效果图 |
| 插画和图片 | 以效果图为准，精确重建或局部裁取效果图 |
| 图标 | 以效果图为准，局部裁取效果图复刻 |
| Logo、顶部横条、品牌字体和颜色 | 以模板或用户提供品牌素材为准 |
| 背景 | 以模板或效果图中可观测背景为准 |

**Hard rule**: 模板只用于提供与效果图一致的品牌资产或原生对象。模板与效果图冲突时，以效果图为准，不得把效果图内容强塞进近似模板版式。

---

## 3. 逐页取证

对每张效果图先建立 `analysis/reference_inventory.md`，再制作 PPT。每页必须记录：

| 类别 | 必须记录的事实 |
|---|---|
| 画布 | 宽高、比例、页面边界和安全区 |
| 文字 | 按阅读顺序逐字转录；保留标点、数字、大小写、换行和段落 |
| 区域 | 每个模块的边界框、内边距、间距和对齐锚点 |
| 字体 | 字体家族、字号、字重、颜色、行距、字距和对齐方式的观测值 |
| 图标 | 外观、语义、颜色、线宽、尺寸、位置、来源和重建方式 |
| 图形 | 形状、圆角、描边、填充、透明度、阴影、连接关系和层级 |
| 图片 | 裁切范围、缩放方式、位置、圆角、遮罩和层级 |
| 不确定项 | 无法辨识的字符、图标或样式；附局部坐标和候选值 |

**Hard rule**: 不得凭记忆制作。每完成一页前重新查看该页原始效果图和对应盘点记录。

**Missing or unclear content**: 放大、裁切并交叉检查原图、模板和用户素材。仍无法可靠辨识时，保留原位置并在计划中列出不确定项，等待用户确认；不得自行猜句子。

---

## 4. 路由与资产

| 条件 | 路由 |
|---|---|
| PPTX 中存在与效果图同版式、同对象结构的页面 | 克隆该页并做原生对象替换或轻改 |
| PPTX 仅提供 Logo、背景、字体、配色或个别图标 | 新建空白页，提取匹配资产后按效果图重建 |
| PPTX 结构与效果图不同 | 新建空白页，禁止为了复用模板改变效果图结构 |
| 只有效果图 | 新建空白页，按效果图测量结果原生重建 |

在 `analysis/route_decision.md` 记录每页路由、复用对象、重建对象、素材来源和不确定项。导入用户素材时复制到项目目录，禁止移动原文件。

**Icon fidelity order**:

1. 仅裁取该图标或插画局部为独立透明图片；不得连同周围文字或大块背景一起裁取。
2. 语义相似但外观不一致的图标不得替代效果图外观。

---

## 5. 复刻计划确认

生成前输出 `analysis/replication_plan.md`：

| 项目 | 内容 |
|---|---|
| 页面对应 | 效果图与输出页的一一对应关系 |
| 逐字文本 | 所有可见文字的转录结果 |
| 几何测量 | 页面网格、模块边界、间距和对齐关系 |
| 对象映射 | 每个文字、图标、图形和图片的原生对象或局部图片实现方式 |
| 资产来源 | 模板、用户素材、图标库、原生重建或局部裁取 |
| 不确定项 | 无法可靠识别且会影响最终内容的项目 |

⛔ **BLOCKING**: 仅当存在会改变文字或关键图标含义的不确定项时，展示局部位置和候选值并等待用户确认。没有此类不确定项时直接执行，不额外请求审美确认。

---

## 6. 原生重建

1. 按效果图页序逐页制作，不重排、不增页、不减页。
2. 先建立画布、背景和主要网格，再放置模块、图形、图片、图标，最后录入逐字文本。
3. 优先使用以下字体基线；若观测字体不同，以观测值为准：

| 层级 | 字体 | 字号 | 字重 |
|---|---|---:|---|
| PPT页标题 | 微软雅黑 | 28 pt | 加粗 |
| 页面关键大标题 / 强调数字 | 微软雅黑 | 18 pt | 加粗 |
| 模块标题 / 表头 / 小标题 | 微软雅黑 | 14 pt | 加粗 |
| 正文 | 微软雅黑 | 默认 12 pt，最低 11 pt | 常规；关键词可加粗 |
| 页面底部总结 | 微软雅黑 | 18 pt | 加粗 |

4. 保留效果图的原始换行、行数、对齐和文本框宽度。文字不适配时调整几何或寻找更准确字体，不修改文字。
5. 复刻可见的圆角、描边、阴影、透明度、颜色、层级和对象间连接关系。
6. 保持文字、基础图形、线条、表格和图标可单独选择与编辑。

**Hard rule**: 不得“优化”留白、对齐、字号、配色、信息层级或视觉风格。效果图中的不规则之处也应复刻，除非用户明确要求修正。

**Hard rule**: 不得添加技能默认内容。演讲备注、动画、转场和额外说明仅在用户明确要求时添加。

---

## 7. 对比验证

使用 PowerPoint 原生渲染输出页为 PNG，并与对应效果图进行并排和半透明叠加对比。至少完成两轮“渲染-对比-修正”；仍有明显差异时继续修正，不得以主观判断提前结束。

| 检查项 | 通过条件 |
|---|---|
| 文字 | 与效果图逐字一致，包括标点、数字、大小写、段落和可见换行 |
| 对象完整 | 所有可见图标、图形、线条、图片和装饰均已出现，无自增对象 |
| 几何 | 模块位置、尺寸、间距、对齐、比例和阅读顺序与效果图贴合 |
| 样式 | 字体、字号、字重、颜色、圆角、描边、阴影和透明度贴合 |
| 图标 | 外观、尺寸、颜色、线宽和位置贴合，不以语义相似替代外观一致 |
| 图片 | 裁切、缩放、遮罩、圆角和层级贴合 |
| 可编辑性 | 文字和可重建视觉对象为独立 PowerPoint 对象；无整页截图背景 |
| 溢出 | 无效果图之外的截断、重叠、越界或异常换行 |
| 回读 | `python scripts/ppt_to_md.py <pptx>` 提取文字与逐字清单一致 |

将差异和修正记录写入 `validation/replication_report.md`。任何未解决差异必须注明页码、对象、原因和限制，不得笼统写“基本一致”。

---

## 8. 交付

`exports/` 只保留最终 PPTX。`validation/` 保留最终渲染 PNG、叠加对比图和 `replication_report.md`。交付时提供绝对路径，并简要报告逐字一致性、对象完整性、版式贴合、图标贴合、可编辑性和未解决差异。
